# Advanced

This project is not stable, and so before long you may find yourself looking for a feature or binding that does not yet exist, or seeing foreign-looking errors such as segmentation faults. The advanced section is designed to help you solve these problems yourself, instead of needing to wait for a maintainer to fix them.

## Development Environment

Most of these topics will involve modifying the source code, so if you do end up having to do that either to add a missing feature or to fix a bug, please contribute it via a pull request.
